# Rebuild Roadmap

## Gate 0: Retire And Reset

- Preserve the failed build at `graybox-retired-2026-08-26`
- Stop the cloud VM and remove the public Play claim
- Delete all procedural presentation and runtime-created input
- Require an authored `UGPVerticalSliceDefinition`; provide no fallback world

## Gate 1: Beauty Corner

- Commission or license original Bruno, guard, P9, and superyacht assets
- Build one final-quality 20 x 20 meter encounter space
- Finish first-person body, full-body shadow/reflection, one guard animation set,
  wet materials, lighting, rain, impacts, weapon sound, and Italian test line
- Match `Docs/Art/vertical-slice-visual-target.png` before expanding the map

## Gate 2: First Encounter

- Author Enhanced Input assets and production movement/camera/weapon feel
- Implement Gorilla Grip, Knuckle Rush, Bruno Button, and Banana Decoy
- Prove ghost, lure, grab, and firearm routes against two production guards
- Add deterministic encounter restart and automated screenshot coverage

## Gate 3: Complete Mission

- Build the authored superyacht route and three enemy archetypes
- Add local perception, interruptible radios, StateTree behavior, and attack limits
- Add ledger objective, two checkpoints, adaptive escape, tender extraction, and scoring
- Record consented Italian performance and localized subtitles

## Gate 4: Package Approval

- Pass `Scripts/validate_vertical_slice.sh` with complete license records
- Complete stealth, alarm, combat, death, checkpoint, and extraction tests
- Sustain local 1080p60 with a 14 ms GPU p95 and input-to-shot below 50 ms
- Eliminate Blueprint errors, missing references, shader hitches, and actionable cook warnings
- Approve the local packaged build before starting or uploading to any cloud VM

## Gate 5: Delivery

- Run a separate 15-minute Pixel Streaming soak only after local approval
- Verify hardware codec, regional input-to-photon p95 below 100 ms, and no drops
- Publish only the exact manifest-bearing commit that passed the prior gates

Console work remains outside this roadmap until platform approval, devkits,
restricted SDK access, secure CI, and an authorized Unreal source build exist.
