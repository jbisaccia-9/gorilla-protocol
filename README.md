# Gorilla Protocol

`Gorilla Protocol` is an original Unreal Engine 5.8 first-person espionage
vertical slice. It replaces the earlier browser prototype with a native UE5
foundation built for modern lighting, production character assets, tactical AI,
and eventual desktop or console development.

The protagonist is Agent Bruno, an original gorilla operative whose spoken
dialogue is Italian. This project is not affiliated with GoldenEye, Donkey Kong,
Nintendo, Rare, MGM, EON Productions, Sony, or Microsoft.

## Current Status

The repository contains a code-complete graybox framework, not finished AAA art.
It provides:

- Lumen global illumination and reflections
- Virtual Shadow Maps, TSR, Nanite-ready Windows settings, and Metal SM6
- Runtime first-person input: move, look, fire, ADS, sprint, reload, and interact
- Single-player health, magazine/reserve ammunition, weapon spread, and headshots
- AI sight and hearing, patrol, investigation, telegraph, burst, stagger, retreat,
  melee, and two-shooter coordination
- A native HUD, runtime test arena, six hostile guards, cipher objective, and
  timed extraction flow
- Italian protagonist dialogue hooks for recorded voice and localized subtitles
- Automated smoke-test scaffolding, offline validation, scalability profiles,
  Git LFS rules, and asset-license tracking
- Pixel Streaming 2 integration plus a pinned UE5.8 signaling, HTTPS, and TURN
  deployment stack for a Linux GPU host

The runtime arena uses Engine basic shapes only so the source project can boot
without Marketplace content. Those shapes are test proxies and must be replaced
before visual review.

## Required Production Assets

Console-quality visuals cannot be generated by C++ scaffolding. The following
must be created, commissioned, or licensed with redistribution rights:

- Hero gorilla body, groom/fur, face rig, first-person arms, and Control Rig
- Gorilla locomotion, weapon, reload, melee, vault, hit, death, and facial animation
- Guard characters, equipment variants, skeletal LODs, and combat animations
- Weapon models, hand poses, recoil sets, attachments, and physical materials
- A modular rain-soaked coastal facility environment with Nanite-ready meshes
- PBR material library, decals, surface detail, glass, foliage, and wetness masks
- Niagara muzzle, tracer, impact, smoke, rain, spark, and alarm effects
- Recorded Italian performance with actor consent, subtitles, Foley, weapons,
  ambience, music, and MetaSound implementation

Every imported asset must be entered in `Licenses/AssetManifest.csv`.

## Prerequisites

- Unreal Engine 5.8
- macOS: full compatible Xcode installation and Metal toolchain
- Windows: a DX12/SM6 GPU and supported Visual Studio toolchain
- Git LFS before adding binary assets
- At least 32 GB RAM recommended
- At least 150 GB free disk space; 200 GB or more is preferable for Engine,
  project assets, caches, and packaged builds

This Mac currently does not have Unreal Engine or full Xcode installed and has
far less than the required free storage. The project therefore cannot be compiled
or launched on this machine until storage and toolchain prerequisites are addressed.

## Open And Run

1. Install Unreal Engine 5.8 and full Xcode or Visual Studio.
2. Install Git LFS and run `git lfs install`.
3. Set `UE_ROOT`, then run `./Scripts/build_editor.sh` to compile the C++ module.
4. Run `./Scripts/bootstrap_project.sh` on macOS/Linux or
   `Scripts/bootstrap_project.ps1` on Windows once to generate the project-owned
   `L_Boot.umap` with a Player Start and switch the startup map configuration.
5. Commit the generated map through Git LFS.
6. Open `GorillaProtocol.uproject` and press Play. The global game mode creates
   the graybox mission at runtime.

On macOS, command-line compilation can be run with:

```bash
export UE_ROOT="/path/to/UE_5.8"
./Scripts/build_editor.sh
./Scripts/run_smoke_tests.sh
./Scripts/run_data_validation.sh
./Scripts/package_mac.sh
```

Shipping builds for Pixel Streaming use `Scripts/package_linux.sh` or
`Scripts/package_windows.ps1` on the corresponding UE5.8 build machine.
For a copy-paste Linux workflow that creates the exact cloud-upload archive, see
[`LINUX_BUILD_README.md`](LINUX_BUILD_README.md).

Source-only validation does not require Unreal:

```bash
./Scripts/validate_project.sh
```

## Browser Streaming

The UE5 build is designed to run in a browser through Pixel Streaming 2. Epic
provides the streaming plugin and reference infrastructure, but not a hosted GPU
instance. See [`Hosting/README.md`](Hosting/README.md) for the complete deployment
topology, firewall rules, secure TURN setup, packaging commands, and remaining
cloud inputs.

A guarded Google Cloud G2/L4 deployment is included under
[`Hosting/gcp/`](Hosting/gcp/README.md). It performs read-only billing, quota,
machine, and region checks before allowing any paid resource creation, and it
includes a `$30` monthly budget alert, automatic idle power-off, a hard per-boot
runtime limit, explicit stop controls, and full teardown commands.

The Google Cloud network, static address, approved L4 quotas, G2/L4 host, licensed
NVIDIA workstation driver, cost budget, and shutdown controls are provisioned.
The host is intentionally stopped, so hourly CPU, GPU, and workstation-license
charges are not running. Persistent disk and reserved-address charges continue.

There is no public UE5 stream yet because this repository has not been packaged
as a Linux Shipping build. Uploading that build is the remaining deployment step;
the old GitHub Pages game is a separate WebGL codebase.

## Controls

- `WASD`: move
- Mouse: look
- Left mouse: fire
- Right mouse: aim down sights
- `Shift`: sprint
- `R`: reload
- `E`: interact with the cipher device

Recover the cipher at the far end of the facility, then return to the green
extraction marker. Eliminating every guard is optional.

## Architecture

- `Characters/`: player and guard pawns
- `Components/`: health and weapon rules
- `AI/`: perception, tactical state machine, and firing-token subsystem
- `Game/`: game mode and mission state
- `Interaction/`: cipher objective and extraction zone
- `World/`: lighting stack and runtime graybox mission
- `UI/`: native fallback HUD
- `Tests/`: UE automation smoke tests
- `Config/`: renderer, platform, navigation, input, tags, and scalability settings

Gameplay state remains in C++. Blueprints should assemble presentation, animation,
audio, effects, and asset references without duplicating combat or mission rules.

## Console Boundary

PS5 and Xbox packaging require platform-holder approval, NDA-restricted SDKs,
development hardware, secure build machines, and an authorized Unreal source
build. No console SDK, certificate, credential, or restricted documentation may
be committed to this repository.
